# Repaso · Estructuras

Material de práctica de `struct` y arreglos de structs (temas de las clases 2 y 3).

| Archivo | Tipo |
|---------|------|
| `index.cpp` | Struct con valores por defecto e inicialización con llaves |
| `ejemplo_resuelto_struct.cpp` | **Resuelto:** registro de mascotas (modelo a seguir) |
| `ejercicio1_libros.cpp` | **Plantilla con `TODO`:** registro de libros |
| `ejercicios_basicos_struct.cpp` | **Calentamiento por completar:** Punto, Rectángulo, Persona, Canción |
| `ejercicios_estructuras.cpp` | **Solo enunciados:** 6 ejercicios (libros, empleados, vehículos, celulares, películas, estudiantes con materias) |

## Secuencia sugerida

1. Leer y ejecutar `ejemplo_resuelto_struct.cpp`.
2. Completar `ejercicios_basicos_struct.cpp`.
3. Completar `ejercicio1_libros.cpp`.
4. Resolver los enunciados de `ejercicios_estructuras.cpp` desde cero.

Patrón común: registrar → mostrar → máximo/mínimo por índice → promedio → filtro.
